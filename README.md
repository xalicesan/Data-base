# ИС спортивных организаций города (вариант 4.10)

Учебный проект по курсу «Базы данных»: проектирование и реализация базы данных
информационной системы спортивных организаций города.

## Стек

- PostgreSQL 17
- SQL (DDL + DML + PL/pgSQL)
- Приложение — TBD (Python/Tkinter или C# WinForms)

## Структура

```
sports_db/
├─ 01_schema.sql      # таблицы, ключи, CHECK, триггеры, представление
├─ 02_data.sql        # тестовые данные
├─ 03_queries.sql     # 13 запросов
├─ reset_db.ps1       # пересоздание базы с нуля
├─ tools/
│  └─ gen_data.py     # генератор 02_data.sql из исходных данных
├─ docs/              # решения, workflow, диаграммы и записка
└─ release/           # дамп для сдачи и вывод запросов
```

## Развёртывание

```powershell
# один раз: создать базу (пароль пользователя postgres)
createdb -U postgres -E UTF8 -T template0 sports_db

# пересоздать схему и данные
.\reset_db.ps1 -PgPassword <пароль postgres>
```

Параметры подключения по умолчанию: `localhost:5432`, пользователь `postgres`.

Проверить запросы:

```powershell
psql -U postgres -d sports_db -P pager=off -f 03_queries.sql
```

Параметры запросов задаются psql-переменными в начале `03_queries.sql`
(вид спорта, разряд, период, тренер, спортсмен, соревнование и т. д.).

Восстановить базу из дампа:

```powershell
createdb -U postgres sports_db
pg_restore -U postgres -d sports_db release/sports_db.dump
```

## Командная работа

Общего сервера нет: у каждого своя локальная база, обмен — через Git.
В репозитории лежат скрипты и дамп, поэтому база воспроизводится
на любом компьютере одной командой.

Подробная инструкция: [docs/workflow.md](docs/workflow.md).

Коротко:

```powershell
git pull
.\reset_db.ps1 -PgPassword <пароль>   # если менялись схема или данные
# правки только в своих файлах
git add <свой файл> && git commit -m "..." && git push
```

## Модель данных

Сущности: вид спорта, разряд, тип сооружения, клуб, организатор,
спортивное сооружение (подтипы: боксёрский клуб, бассейн, манеж),
спортсмен, тренер, мероприятие, соревнование, участие.

Ключевые правила целостности:

- вид спорта на сооружении должен соответствовать его оборудованию
  (бокс — ринг, ПСВ — вышка, баскетбол — кольцо, волейбол — сетка);
- соревнование проводится только на сооружении, где разрешён этот вид спорта;
- спортсмен выступает только по виду спорта, который тренирует;
- призовые места в одном соревновании не дублируются;
- клуб имеет ровно один вид спорта; спортсмен состоит в одном клубе.
