# ИС спортивных организаций города (вариант 4.10)

Учебный проект по курсу «Базы данных»: проектирование и реализация базы данных
информационной системы спортивных организаций города.

## Развёртывание

```powershell
# один раз: создать базу
createdb -U postgres -E UTF8 -T template0 sports_db

# пересоздать схему и данные
.\reset_db.ps1
```

Параметры подключения по умолчанию: `localhost:5432`, пользователь `postgres`.

## Модель данных

Сущности: вид спорта, разряд, тип сооружения, клуб, организатор,
спортивное сооружение (подтипы: боксёрский клуб, бассейн, манеж),
спортсмен, тренер, мероприятие, соревнование, участие.

Ключевые правила целостности:

- вид спорта на сооружении должен соответствовать его оборудованию
  (бокс — ринг, ПСВ — вышка, баскетбол — кольцо, волейбол — сетка);
- соревнование проводится только на сооружении, где разрешён этот вид спорта;
- спортсмен выступает только по виду спорта, который тренирует;
- призовые места в одном соревновании не дублируются;
- клуб имеет ровно один вид спорта; спортсмен состоит в одном клубе.
